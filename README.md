# Font Merger

GitHub Pages ready single-page Bangla + English font merger.

## Use
1. Upload the Bangla/base font.
2. Upload the English/Latin font.
3. Click **ফন্ট মার্জ করুন**.
4. Download the generated merged TTF.

The app uses Pyodide + FontTools in the browser. No font file is sent to a server by this page.

## GitHub Pages
Upload `index.html` to a repository and enable:
Settings → Pages → Deploy from branch → main → /root
